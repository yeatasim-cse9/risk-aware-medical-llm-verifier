# MASTER 01F-R6-R — durable private aggregate stages

R6 is complete. Do not rerun it. Historical archive commit fa868d137fbd4f95eb09c29c9dfc946394b4b283 remains unchanged. Existing synthetic Kaggle resume controller is read-only and stays so.

This new small standard-library module `scripts/e1_master01fr6r_checkpoint_v1.py` provides create-only remote checkpoints and a complete aggregate report in the **dedicated private evidence repository**. Each record binds a reviewed plan, source commit, input and recipe digests, stage index, exact numerical metric schema and previous record digest. It verifies repository identity/privacy before reads and writes, checks remote blob and exact readback, stops on gaps, conflicting plans, malformed values or ambiguous writes. No raw medical text, identifiers, predictions, model/optimizer state, or credentials are allowed in the record format. Numeric aggregate disclosure still requires human review; the schema is not a data-loss prevention system.

Use one operator and one active notebook per run ID. Never overwrite stage files or reuse a run ID for a different plan. Remote files are append-only by this client, not immutable against a repository administrator. A hash chain checks consistency, not independently trusted scientific truth. Concurrent workers could duplicate computation before a create conflict. No automatic Kaggle submission or blind retry. After interruption first reconcile remote job status and then resume with the same plan, reviewed pin and fresh authorization where required. A completed run returns the saved report without computing. Only complete deterministic independent stages are recoverable; data acquisition, batch inference, model state and exact mid-stage continuation require task-specific authorized adapters/storage. Do not claim these have been implemented. A failure before remote commit can lose that stage.
